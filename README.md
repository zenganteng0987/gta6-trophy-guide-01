Leonida Legend is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy carries its official name, description and grade, a guide written for this entry in our own words with its sources named beside it, and a flag when it may be missed — only one trophy can be, Positive Mental Attitude, and the guide says exactly how to keep it safe in Chapter 1. A five-stage roadmap leads to the platinum, and the checklist saves your progress in the browser, exports it to a file, imports it back, filters by kind, and hides story spoilers until you earn them. Where no unlock method is confirmed at launch, the guide says so honestly instead of guessing.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. To build the submission output:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
